### BUG FIXES

[9fd0bfad](https://github.com/pingidentity/terraform-provider-pingfederate/commit/9fd0bfad) `resource/pingfederate_oauth_access_token_manager`: Fixed an issue where `sequence_number` could not be configured. The attribute is now Optional in addition to Computed, allowing the sequence number (embedded in the `pi.atm` claim of issued access tokens) to be pinned to a specific value. If not configured, a server-assigned value is used, and the previously-assigned value is retained if the attribute is later removed from configuration. [#634](https://github.com/pingidentity/terraform-provider-pingfederate/pull/634)
[4a98e27d](https://github.com/pingidentity/terraform-provider-pingfederate/commit/4a98e27d) Added validation to prevent inconsistent result errors due to empty `expression_criteria` and trailing newlines for `EXPRESSION` values in `attribute_contract_fulfillment` [#635](https://github.com/pingidentity/terraform-provider-pingfederate/pull/635)
[5b21c2c7](https://github.com/pingidentity/terraform-provider-pingfederate/commit/5b21c2c7) `resource/pingfederate_oauth_token_exchange_processor_policy`: Fixed an issue where creation could silently fail when many policies were created concurrently. The create is now verified and re-issued if the policy was not persisted. [#636](https://github.com/pingidentity/terraform-provider-pingfederate/pull/636)
